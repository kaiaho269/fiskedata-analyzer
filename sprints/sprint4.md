# Sprint 4 — Follow vessels across fishing areas

## Goal
Move from ranking vessels in one area to following selected vessels through the wider dataset.

## Work completed
- Extended the analysis layer with vessel-following capability.
- Added the ability to track selected vessel IDs across the dataset.
- Returned area, species, catch value, vessel name and registration for the tracked vessels.

## What we learned
A vessel is a much more useful analytical unit than an isolated catch record. Once vessel identity is stable, FA can investigate behaviour across areas and species.

## Direction
FA began evolving from a local catch report into a fleet-intelligence tool.

## Result
The foundation for the later concept **HOME AREA → FLEET → CATCH → VALUE → ELSEWHERE** was established.
