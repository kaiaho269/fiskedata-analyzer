# Sprint 3 — Vessel names and registrations

## Goal
Make vessel-ranking results understandable to humans rather than exposing only internal identifiers.

## Work completed
- Added vessel names to the value-ranking results.
- Added registration marks to the results.
- Kept the internal vessel identity available for analytical joins/tracking.

## What we learned
Human-readable identity and analytical identity are different responsibilities. FA needs both.

## Direction
The project began moving from raw data analysis toward an investigation interface where a user can recognize the real vessel behind a result.

## Result
Fleet results became substantially more useful for real-world investigation.
