# Sprint 1 — Initial working version

## Goal
Create the first working version of Fiskedata Analyzer against the official 2025 fisheries catch dataset.

## Work completed
- Established the initial Python/Streamlit analysis project.
- Connected the 2025 Fiskeridirektoratet catch data to DuckDB.
- Built the first working analysis path from dataset to results.
- Established the initial vessel/catch analysis foundation.

## What we learned
The project could already answer concrete questions from official catch data rather than being only a UI experiment.

## Direction
FA started as a practical fisheries-data analysis tool. The next step was to make it useful for investigating vessels, catch and value rather than simply displaying records.

## Result
A functioning technical foundation existed and could be extended incrementally.
