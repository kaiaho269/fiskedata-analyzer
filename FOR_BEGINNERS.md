# FA — For Beginners

Welcome to **Fiskedata Analyzer (FA)**.

If you are new to software development, Git, GitHub, Python, or all of the above, this file is for you.

You do **not** need to understand the whole project at once.

FA is being developed in small, understandable steps. The purpose of this guide is to explain the structure and the basic ideas behind the development process.
